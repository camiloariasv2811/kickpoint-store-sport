# Kickpoint Evolve

Quiero que construyas una aplicación web completa para mi empresa KICKPOINT, una empresa dedicada a la venta y distribución de ropa deportiva al mayor y al detal.

IMPORTANTE: esto debe ser una APLICACIÓN WEB, no un programa para instalar en una computadora.

Debe funcionar mediante un enlace desde cualquier navegador y ser totalmente responsive para:

Teléfonos

Tablets

Computadoras

La aplicación debe estar preparada para posteriormente publicarse en internet con un dominio propio.

1. CONCEPTO DE KICKPOINT

KICKPOINT vende ropa deportiva.

Las principales categorías serán:

FÚTBOL

Franelas de equipos de fútbol

Jerseys

Equipaciones

GYM

Leggins

Conjuntos deportivos

Shorts

Tops

Franelas deportivas

Chaquetas

MARCAS

Alo

On

Otras marcas

Pero las categorías NO deben estar limitadas a estas.

El administrador debe poder crear, editar y eliminar categorías y subcategorías desde el panel administrativo.

2. DOS PORTALES DENTRO DE LA MISMA APLICACIÓN

Quiero una sola aplicación web con dos áreas completamente separadas.

PORTAL DEL CLIENTE

Será público y accesible mediante un enlace.

Por ejemplo:

/catalogo

El cliente podrá:

Ver catálogo

Ver categorías

Buscar productos

Seleccionar talla

Seleccionar color

Seleccionar cantidad

Agregar al carrito

Subir comprobante

Consultar estado del pedido

Ver tracking

El cliente NO debe tener acceso al panel administrativo.

3. PORTAL ADMINISTRATIVO

Debe existir una zona protegida por login.

Por ejemplo:

/admin

Debe requerir autenticación.

El administrador podrá:

Administrar productos

Administrar categorías

Administrar inventario

Registrar entradas de mercancía

Registrar ventas

Administrar pedidos

Ver comprobantes

Aprobar pagos

Administrar clientes

Consultar estadísticas

Consultar reportes

Configurar métodos de pago

La información administrativa nunca debe estar disponible para un usuario normal.
